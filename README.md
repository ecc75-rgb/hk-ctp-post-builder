# HK CTP Post Builder

Haber Kıbrıs için CTP milletvekili aday görseli hazırlama aracı.

## GitHub Pages adresi
https://ecc75-rgb.github.io/hk-ctp-post-builder/

İlk kurulum: GitHub deposu > **Settings > Pages > Build and deployment**: **Deploy from a branch**; branch: **main**, folder: **/(root)**; **Save**. GitHub Pages etkinleşince yayınlanır.

## Mac / Safari kullanımı
1. Siteyi açın.
2. **Görsel paketini içeri aktar** seçeneğinden `HK_CTP_Post_Builder.zip` seçin. ZIP'ı açmanız veya Windows başlatıcısı çalıştırmanız gerekmez.
3. İsterseniz **Impact.ttf** ve **Tungsten-Bold.ttf** font dosyalarını siteye yerel olarak yükleyin; GitHub'a yüklenmezler.
4. İlçe seçin, aday havuzundan kişi ve sıralama belirleyin.
5. **PNG İndir** ile 1080 × 1350 görsel indirin.

## İlçeler
- Lefkoşa: 16
- Girne: 12
- Gazimağusa: 12
- İskele 5 / Güzelyurt 3 / Lefke 2: tek görsel

**Önemli:** Site ön seçim sonuçlarını otomatik hesaplamaz. Açıklanan listeyi olduğu gibi girin ve yayınlamadan önce sıralama, kontenjan ve kişi fotoğraflarını resmî kaynaktan doğrulayın.

Kod ve arayüz bu depoda; PSD şablonlar, fotoğraflar ve üçüncü taraf fontların lisanslı kopyaları herkese açık depoya yüklenmez.
